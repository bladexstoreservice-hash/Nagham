# 🎵 Discord Music Bot — 24/7 Local MP3 Player

بوت موسيقى بسيط لسيرفر Discord، يشغّل ملفات MP3 محلية على مدار الساعة مع لوحة تحكم تفاعلية.

## المتطلبات

- **Node.js** 22.12 أو أحدث
- **FFmpeg** (يُثبّت تلقائياً عبر `ffmpeg-static`)
- صلاحيات البوت المناسبة في السيرفر
